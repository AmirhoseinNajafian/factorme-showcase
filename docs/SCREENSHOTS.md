# Interface screenshots

The images in this folder are UI preview captures from the FactorMe 2.10.0 development snapshot. They show a Persian, right-to-left interface and use sample/test content.

| File | What it shows |
| --- | --- |
| `dashboard-mobile.png` | Mobile dashboard, summary card, quick actions, and bottom navigation |
| `invoice-editor-mobile.png` | Customer details, line items, totals, and invoice actions |
| `invoice-list-mobile.png` | Saved invoices screen and empty state |
| `account-settings-mobile.png` | Business profile and invoice appearance options |
| `authentication-flow.png` | Sign-up and sign-in experience |

These are illustrative product previews. They are not a promise that a public service is currently available, and sample values shown in the captures are not real customer records.

When replacing images with newer captures, keep the same filenames where practical so README image links remain valid. Prefer clear, current screenshots without personal customer information, secrets, or browser/account identifiers.
