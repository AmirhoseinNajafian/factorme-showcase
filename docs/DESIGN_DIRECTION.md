# Design direction

## Visual identity

FactorMe uses a distinctive pixel-art crocodile mascot as its recognizable brand mark. The mascot is paired with a restrained interface palette and should remain legible at small sizes.

## Interface principles

- Persian-first labels and right-to-left layout.
- Minimal visual noise and clear grouping.
- Consistent spacing, alignment, and control sizes.
- Unified button colors, text contrast, hover, focus, and disabled states.
- Responsive layouts for mobile, tablet, and desktop.
- Motion should be subtle, quick, and respectful of reduced-motion preferences.
- Forms should keep entered data when users add or remove invoice rows.

## Core palette

The current interface direction is based on these approximate UI colors:

| Role | Color | Hex |
| --- | --- | --- |
| Main text / deep surfaces | Deep charcoal-teal | `#172126` |
| Accent | Dark teal | `#16252B` |
| Accent highlight | Aqua | `#19C7C8` |
| Soft highlight | Mint | `#56D8BD` |
| Page background | Cool light gray | `#F2F4F5` |
| Surface | White | `#FFFFFF` |
| Secondary surface | Soft gray | `#F8F9F9` |

These values document the design direction, not a public CSS API. The interface may evolve.

## Typography

The product interface uses Persian-friendly typefaces and lightweight, readable text styles. Text hierarchy should remain consistent across buttons, labels, headings, navigation, and invoice output.

## Mascot usage

Use the crocodile mascot as a brand cue, not as decoration on every card. Prefer the transparent/standalone mark for compact interface placements and the branded social-preview artwork for promotional surfaces. Avoid multiple avatar-like mascots competing with the user's own account identity.
