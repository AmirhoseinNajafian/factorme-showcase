# Project overview

## At a glance

- **Product:** FactorMe (فاکتورمی)
- **Category:** Invoice creation and small-business billing workspace
- **Primary interface language:** Persian
- **Layout direction:** Right-to-left (RTL)
- **Product owner and developer:** Amirhosein Najafian
- **Showcase snapshot:** UI and feature set represented by the 2.10.0 development package
- **Repository type:** Documentation and visual showcase only

## The idea

Many independent workers and small businesses need to send clear invoices, but a one-size-fits-all document rarely reflects the identity of every business. FactorMe brings invoice creation and visual customization into one Persian-first workspace.

## Who it is for

FactorMe is designed with a broad range of everyday business workflows in mind: service providers, tradespeople, retailers, freelancers, consultants, and small teams.

## Product principles

1. **Persian-first:** natural Persian content and a consistent RTL experience.
2. **Clear by default:** useful hierarchy, readable typography, and uncluttered forms.
3. **Your business, your invoice:** logo, colors, type, layout, and optional invoice sections.
4. **Practical workflow:** create, review, save, search, edit, print, and share.
5. **Separate workspaces:** each account should only access its own business information and invoices.
6. **Respect existing work:** provide a path to bring forward invoices from the older browser-based version.

## What this repository contains

This repository contains the product story, feature descriptions, brand references, interface screenshots, a high-level workflow, and project notes. It deliberately excludes application source code, server code, package files, database schemas, backups, secrets, and user/customer records.

## Product editions

The product has been prepared in two separate forms:

- **Local preview edition:** for local evaluation and QA.
- **Hosting edition:** a PHP and MySQL package for compatible hosting environments.

The two application packages are distributed separately from this public showcase. This repository does not contain installation files or promise a public live demo.
